# Functional Nutrients — Homepage Preview

A polished, responsive single-page homepage concept for presenting the first look of Functional Nutrients to prospective clients.

## Stack
- React 18 + JavaScript
- Tailwind CSS 3
- Vite
- XML sitemap

## Run locally
Requires Node.js 18+.
```bash
npm install
npm run dev
```
Open the localhost URL shown by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Homepage sections
- Hero / brand introduction
- Our approach
- Featured ingredient portfolio
- Consultancy ecosystem preview
- Contact enquiry form
- Footer and brand ownership line

## Important before client presentation / launch
- The contact form uses a `mailto:` link and does not store leads.
- The hero currently uses a remote stock photograph; replace with approved company photography if available.
- Confirm product claims and descriptions with the company before public launch.
- Add verified office address, phone number, founder details and product technical sheets when approved.
